ESP-32 Balancing Robot

❮ ❯

This project is a self-balancing robot built on the ESP32 platform using an MPU6050 IMU for tilt sensing and stepper motors for movement.

The Control System

I used a cascaded PID setup to keep everything stable. The outer PI loop handles the velocity by figuring out the right lean angles while the inner PD loop keeps it balanced. It pulls tilt data from the IMU and calculates motor corrections 100 times every second.

Wireless PS4 Control

For steering, I am using a PS4 controller connected via the Bluepad32 library. The left stick controls the throttle and the X axis handles the steering. I also added some adaptive filtering and speed dependent gains so it does not get twitchy or flip over when you are turning at high speeds.

Sensor Fusion

To get the tilt angle right, I went with a complementary filter instead of a heavy Kalman filter. It basically trusts the gyroscope for 99 percent of the data to get that fast response, and then uses the accelerometer for the last 1 percent just to fix any drift. It is super efficient and keeps the accuracy within 0.2 degrees.

Efficiency and Processing

The code is entirely non-blocking and event-driven. Since the ESP32 has two cores, I split the workload to keep it responsive. Core 1 is dedicated to the time-critical stuff like balance math and pulsing the stepper motors. Meanwhile, Core 0 handles the Bluetooth connection. I also bumped the I2C speed to 400kHz and disabled the standard BLE to make sure there is zero lag in the controls.

Quadcopter Drone Build

❮ ❯

Following the industry-standard FPV architecture, I built a custom high-performance quadcopter from the ground up with a focus on clean electrical assembly and control theory.

  • Assembled a high-strength carbon fiber frame designed for durability and optimal weight distribution of the electronic stack.
  • Soldered a 4-in-1 Electronic Speed Controller (ESC) to high-KV brushless motors, ensuring clean signal paths and robust power delivery for 6S battery voltage.
  • Configured the Betaflight flight controller firmware, including motor resource remapping and peripheral setup for the ELRS radio link and FPV video system.
  • Performed field-tuning of the PID (Proportional-Integral-Derivative) controller to eliminate prop-wash oscillations and achieve a "locked-in" flight feel.
  • Implemented Blackbox data logging to analyze flight performance and fine-tune dynamic notch filters for motor noise reduction.
